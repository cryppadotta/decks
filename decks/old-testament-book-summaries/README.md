# Old Testament Book Summaries

One-sentence summaries of all 39 books of the Protestant Old Testament canon.

The goal is to memorize the main argument, theological burden, or redemptive-historical role of each book rather than merely a list of contents. The summaries are written from a broadly Reformed evangelical perspective.

## Anki deck path

`Bible Knowledge::Old Testament::Book Summaries`

## Tags

- `OT::Pentateuch`
- `OT::Historical_Books`
- `OT::Wisdom_Poetry`
- `OT::Major_Prophets`
- `OT::Minor_Prophets`

## Files

- `cards.tsv` — canonical editable source
- `build.py` — dependency-free Python builder
- `dist/old-testament-book-summaries.apkg` — generated Anki package

## Build

```bash
python3 build.py
```

Or from the repository root:

```bash
make ot-book-summaries
```
