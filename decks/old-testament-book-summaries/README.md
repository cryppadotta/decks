# Old Testament Book Summaries

One-sentence summaries of all 39 books of the Protestant Old Testament canon.

The goal is to memorize the main argument, theological burden, or redemptive-historical role of each book rather than merely a list of contents. The summaries are written from a broadly Reformed evangelical perspective.

## Source

- `cards.tsv` — canonical source; columns are `Front`, `Back`, and `Tags`.
